# 3D Avatar Models Directory

Place your 3D avatar `.glb` or `.gltf` models here.

### Verity Model:
- Source: [https://skfb.ly/pLRPF](https://skfb.ly/pLRPF)
- Save file as: `public/models/verity.glb`

SignSync automatically attempts to load `/models/verity.glb`. If the file is not yet present, SignSync renders the built-in procedural rigged humanoid 3D armature with real-time ISL bone tracking, and also allows direct uploading of any `.glb` model via the in-app 3D Avatar controls!
